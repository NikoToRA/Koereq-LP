## 本セッションでの主要変更点

- ヒーローセクション（構造）
  - 背景をフルスクリーンのレイヤー化（画像/動画を背面、テキスト/CTAを前面）
  - 見出しを一行固定で中央表示（折返し禁止）
  - 50秒動画ボタンを削除
  - CTA文言を「今すぐあなたの時間を取り戻す」+ 小文字サブ「お問い合わせ」に変更
  - CTAを画面下寄せ（PC/スマホで押しやすい位置に固定）。モバイルは全幅近くに拡大
  - デスクトップは背景動画（autoplay muted loop playsinline）、タブレット/モバイルは静止画フォールバック

- ヒーロー下「導入実績」数値行（視覚表現の再設計）
  - 表現を「記録時間 80% 削減で → 16時間/月 の自由を」に変更
  - 80を青、16を赤で強調。単位（%・時間/月）は数字の1/3サイズで控えめに
  - 「20分の記録が2分で完了」を80%直下に配置
  - 矢印は絵文字からSVG（青→緑のグラデ）に変更
  - ブロック全体は中央揃え、「記録時間」は80%に左合わせ、「削減で」と「の自由を」は同等サイズ

- そのほかのUI/構成変更
  - 一時的に入れていたマイクロコピー（取り戻す？どうやって？）は撤去
  - 「最もシンプルな音声入力カルテ コエレク」タグは現在非表示（要望で一旦削除）

- 配信/セキュリティ・運用
  - OGP画像プレースホルダを設定（`/images/ogp.jpg`）
  - RenderのCSPを追加（Google Fonts/GAを考慮）
  - ライブリロード用 `dev_server.py` と簡易サーバ `simple_server.py` を追加
  - `#contact-form` / `#download` / `#consultation` の仮セクション追加（リンク切れ回避）

## ヒーロー素材の適用方法

- 背景動画（任意）
  - 置き場所: `videos/hero.mp4`（必要に応じて `videos/hero.webm` も）
  - 先読み静止画: `images/hero/poster.jpg`
- 静止画のみで運用する場合
  - `index.html` のヒーローセクションに: `style="--hero-image: url('/images/hero/poster.jpg')"`

- 数字のサイズは `css/style.css` の `.stat-number` の `clamp()` で制御
